# Полный гид по документам для поступления в университеты США и Европы

**Для российских граждан, планирующих undergraduate admission в 2027 году**

---

## 1. Общий чеклист документов

Ниже перечислены ВСЕ документы, которые могут потребоваться для подачи заявления на бакалавриат за рубеж. Не все университеты запрашивают всё сразу — некоторые документы требуются только на этапе подачи, другие — после зачисления или для визы.

### Документы, которые нужны практически везде

| # | Документ | Этап |
|---|----------|------|
| 1 | Заграничный паспорт (действителен минимум 6 месяцев после начала учебы) | Подача + виза |
| 2 | Аттестат о среднем общем образовании (или справка об окончании 11 классов) | Подача |
| 3 | Школьный транскрипт (application transcript / grade report) | Подача |
| 4 | Перевод аттестата и транскрипта на английский (certified translation) | Подача |
| 5 | Рекомендательные письма (2–3 штуки) | Подача |
| 6 | Сопроводительное эссе / Personal Statement / Motivation Letter | Подача |
| 7 | Результаты языковых тестов (TOEFL / IELTS / Duolingo) | Подача |
| 8 | Результаты стандартизированных тестов (SAT / ACT, если требуются) | Подача |
| 9 | CV / Resume (краткое) | Подача (часто опционально) |
| 10 | Подтверждение финансовых средств (bank statement / affidavit of support) | После зачисления + виза |

### Документы, которые нужны в специфических случаях

| # | Документ | Когда нужен |
|---|----------|-------------|
| 11 | Апостиль на аттестат (Hague Apostille) | Только для определенных стран (Германия, Нидерланды, Швейцария) |
| 12 | Credential evaluation (WES, ECE, SpanTran) | Некоторые US университеты, большинство требует для российских дипломов |
| 13 | Транскрипт из вуза (если уже учишься в CUM / другом вузе) | Если подаешься как transfer student или уже начал высшее образование |
| 14 | Портфолио (portfolio) | Архитектура, дизайн, изобразительное искусство, иногда CS |
| 15 | CSS Profile (College Scholarship Service) | US private universities для финансовой помощи |
| 16 | Справка о прививках (immunization record) | После зачисления, для заселения в кампус |
| 17 | Справка об отсутствии судимости (police clearance) | Редко, для определенных программ или виз |
| 18 | СЕРТИФИКАТ о знании немецкого / французского | Для программ на национальных языках |
| 19 | SEVIS fee receipt (I-901) | Только для US визы F-1 |
| 20 | DS-160 confirmation | Только для US визы |
| 21 | IHS payment (Immigration Health Surcharge) | Для UK Student Route visa |
| 22 | Tuberculosis test certificate | Для UK visa, если из listed country (Россия — listed) |
| 23 | Blocked account (Sperrkonto) | Для немецкой student visa |

### Документы, которые нужно иметь в оригинале (не копии)

- Заграничный паспорт
- Аттестат о среднем общем образовании
- Банковские выписки (при подаче на визу)

## 2. Документы по типу университетов

### 2.1 US Private Universities (Common App)

**Платформа подачи:** Common Application (commonapp.org) — используют 1000+ университетов, включая все Ivy League, Stanford, MIT, Duke, Northwestern.

**Что требуется:**

1. **Common App основная часть:**
   - Personal Essay (650 слов, выбор из 7 тем)
   - Additional Information essay (опционально)
   - Список extracurricular activities (до 10)
   - Список наград и достижений
   - Academic history (самостоятельно вводишь оценки)

2. **Дополнительные эссе для каждого университета (Supplemental Essays):**
   - Количество: 0–4 эссе в зависимости от университета
   - Темы: "Why this college?", "Why this major?", diversity essay, community impact
   - Средний объем: 100–400 слов каждое

3. **School Report и Transcript:**
   - Counselor recommendation + School Report (заполняет школьный психолог/директор)
   - Official transcript (официальный транскрипт из школы)
   - Mid-Year Report (если подаешь до получения итоговых оценок за 11 класс)
   - Final Report (после окончания школы)

4. **Teacher Recommendations:**
   - 2 письма от учителей основных предметов (core subjects)
   - Желательно: математика/естественные науки + гуманитарный предмет
   - Можно добавить 3-е письмо (дополнительное, не от родственников)

5. **Test Scores:**
   - TOEFL / IELTS / Duolingo (практически всегда для носителей русского)
   - SAT / ACT — сейчас test-optional во многих, но сильные баллы помогают
   - AP Exam scores (если сдавал)
   - SAT Subject Tests — отменены в 2021 году

6. **Financial Documentation:**
   - CSS Profile (collegeboard.org/css-profile) — стоимость $25 за первый университет, $16 за каждый следующий
   - IDOC (Institutional Documentation Service) — загрузка финансовых документов
   - Налоговые декларации родителей (translated)
   - Bank statements / proof of assets
   - Non-custodial parent statement (если родители разведены)

7. **Специальные требования:**
   - Portfolio (для архитектуры, дизайна, некоторых CS программ — Carnegie Mellon, MIT)
   - Interview (alumni interview, опционально или приглашение)
   - Demonstrated interest (посещение кампуса, virtual tours, emails)

**Что нужно переводить:**
- Аттестат (не всегда требуют — достаточно credential evaluation)
- Транскрипт (через credential evaluation или certified translation)
- Налоговые декларации (для CSS Profile)

**Что нужно апостилировать:**
- Для US private universities **апостиль НЕ тРЕБУЕТСЯ** на аттестат. Достаточно credential evaluation.

**Важные даты:**
- Early Decision / Early Action: 1–15 ноября
- Regular Decision: 1–10 января
- CSS Profile: подается одновременно с основной заявкой или раньше

### 2.2 US Public Universities (UC, ApplyTexas, Coalition, etc.)

**Ключевые отличия от private:**

1. **Отдельные системы подачи:**
   - **UC (University of California):** UC Application (apply.universityofcalifornia.edu) — подаешь один раз на все 9 кампусов
   - **ApplyTexas:** для Texas A&M, UT Austin и других
   - **Coalition Application:** менее популярна, но используется University of Washington, Rutgers и др.
   - **Некоторые:** собственный портал (University of Illinois, Georgia Tech)

2. **Нет CSS Profile:**
   - Публичные университеты обычно не требуют CSS Profile
   - Финансовая помощь для international students крайне ограничена или отсутствует
   - Многие public universities вообще не предоставляют aid international students

3. **Personal Statement / Essays:**
   - UC: Personal Insight Questions (PIQ) — выбор 4 из 8 тем, 350 слов каждая
   - ApplyTexas: Essay A + Essay B (опционально)
   - Обычно меньше supplemental essays, чем у private

4. **Рекомендательные письма:**
   - Многие public universities НЕ требуют recommendation letters для international students
   - Некоторые принимают опционально (UC — не используют в admission decision)

5. **Out-of-state / International requirements:**
   - Международные студенты платят out-of-state tuition (в 2–3 раза выше, чем резиденты штата)
   - Документы те же, но proof of funds требуется сразу или после admission

6. **Credential Evaluation:**
   - Часто требуется обязательно (WES, ECE)
   - Некоторые принимают только определенные агентства

7. **Test Scores:**
   - TOEFL / IELTS обязательны почти всегда
   - SAT / ACT — часто required (особенно для больших public schools), не так много test-optional

**Стоимость application fees:**
- UC: $70 за кампус (для international), можно fee waiver
- ApplyTexas: $50–$75
- Остальные: $50–$90

### 2.3 UK Universities (UCAS)

**Платформа:** UCAS (ucas.com) — единая система для всех UK universities.

**Структура заявки:**

1. **Personal Statement:**
   - 4000 characters (including spaces) или 47 строк
   - ОДНО эссе на все 5 университетов
   - Фокус: academic interest, why this subject, relevant experience, career goals
   - НЕ университет-специфичное (в отличие от US)

2. **Academic Reference:**
   - ОДНА reference letter (от школьного учителя / counselor)
   - Заполняется через UCAS систему
   - Должна оценивать academic potential

3. **Predicted Grades:**
   - Если еще не окончил школу — школа предоставляет predicted grades
   - Для российских школьников: часто основывается на текущих оценках + mock exams

4. **Education History:**
   - Вводишь все квалификации
   - Russian high school diploma — не является direct equivalent A-Levels
   - Некоторые университеты требуют foundation year или specific subjects

5. **Entry Requirements для российских студентов:**
   - Многие топовые университеты требуют A-Levels, IB, или foundation year
   - Для Oxford / Cambridge: A*A*A equivalent (нужны foundation или exceptional grades)
   - Для Warwick, Manchester, Edinburgh: AAB–AAA equivalent

6. **Language Requirements:**
   - IELTS Academic: обычно 6.5–7.5 overall, no band below 6.0
   - TOEFL iBT: 90–110
   - Some accept Duolingo: 120–135

7. **Дополнительные требования:**
   - **Oxbridge:** admissions tests (MAT, TMUA, NSAA, TSA, LNAT — в зависимости от курса)
   - **Interviews:** обязательны для Oxford, Cambridge, Imperial (некоторые курсы), UCL (некоторые курсы)
   - **Portfolio:** для art, architecture, design
   - **Written work:** для humanities в Oxford

8. **Виза и после зачисления:**
   - **IHS (Immigration Health Surcharge):** £776 за год (платится при подаче на визу)
   - **TB test:** обязателен для российских граждан — £100–£200 в approved clinic (Москва, СПб)
   - **Financial proof:** £11,385–£13,347 за год жизни (в зависимости от локации) + tuition fees, в банке минимум 28 consecutive days

9. **Application Fee:**
   - £28.50 за 1 choice, £37 за 2–5 choices

**Даты:**
- Oxford, Cambridge, Medicine, Veterinary, Dentistry: 15 октября
- Все остальные: 31 января (Equal Consideration Deadline)
- Late applications: после января, но places may be limited

### 2.4 German Universities (Uni-Assist)

**Система подачи:**
- **Uni-Assist:** для большинства international students (uni-assist.de)
- **Direct application:** некоторые universities принимают напрямую
- **hochschulstart.de:** для medicine, dentistry, pharmacy (numerus clausus)

**Ключевые документы:**

1. **Hochschulzulassungsberechtigung (HZB):**
   - Это recognition, что твой российский аттестат дает право поступать в немецкий вуз
   - Российский аттестат о среднем общем образовании (11 классов) + 2 года вуза в России = direct HZB
   - Либо аттестат + 1 год Studienkolleg = direct HZB
   - Проверяется через anabin database (anabin.kmk.org) или через Uni-Assist

2. **Studienkolleg (Foundation Year):**
   - Если аттестат НЕ признается как direct HZB — нужен 1 год подготовки
   - 2 семестра, бесплатный, но на немецком языке
   - Aufnahmeprufung (вступительный экзамен) — тест на немецком + предметы
   - Feststellungsprufung (финальный экзамен) — дает HZB
   - Специальности: M-Kurs (medicine), T-Kurs (technical), W-Kurs (economic), G-Kurs (humanities)
   - Для CS: T-Kurs (Mathematics, Physics, Chemistry)

3. **Language Requirements:**
   - Для немецкоязычных программ: DSH-2, TestDaF TDN 4, Goethe C2, telc C1
   - Для англоязычных программ (бакалавриат их мало): IELTS 6.5+ / TOEFL 80+
   - Многие CS программы на английском на магистратуре, но бакалавриат — в основном на немецком

4. **Translations and Apostille:**
   - **Апостиль:** НЕ требуется для подачи в Uni-Assist (но может потребоваться для визы)
   - **Перевод:** certified translation на немецкий или английский (Uni-Assist принимает оба)
   - Все документы должны быть нотариально заверены + переведены

5. **Blocked Account (Sperrkonto):**
   - Требуется для student visa
   - Сумма: €11,904 на год (€992/месяц) — сумма обновляется ежегодно
   - Провайдеры: Coracle, Expatrio, Fintiba
   - Стоимость открытия: €49–€150
   - Месячный fee: €5–€10
   - Деньги блокируются — можно снимать только €992/месяц
   - Альтернатива: scholarship confirmation, garantor (редко для россиян)

6. **Uni-Assist Processing:**
   - Стоимость: €75 за первый university, €30 за каждый следующий (макс. €225)
   - Срок обработки: 4–6 недель
   - Документы загружаются онлайн + некоторые отправляются по почте (check specific requirements)

7. **Виза:**
   - Student visa (Visum zu Studienzwecken)
   - Срок ожидания: 6–12 недель в российских консульствах (Москва, СПб, Екатеринбург, Новосибирск, Калининград)
   - Требования: admission letter, blocked account, health insurance, passport, biometric photos, proof of language

**Даты:**
- Winter semester (начало октября): deadline 15 июля
- Summer semester (начало апреля): deadline 15 января
- Uni-Assist: рекомендуется подавать минимум за 8 недель до deadline

### 2.5 Dutch Universities (Studielink)

**Система подачи:**
- **Studielink:** studielink.nl — национальная система
- **Основной портал университета:** многие требуют дополнительную регистрацию на своем сайте

**Ключевые документы:**

1. **Diploma Equivalency:**
   - Российский аттестат (11 классов) = Dutch VWO diploma (условно)
   - Проверяется через Nuffic (nuffic.nl) — Dutch organization for internationalization in education
   - Для CS и engineering: нужны strong grades в mathematics и physics

2. **Numerus Fixus (Fixed Quota):**
   - Для Computer Science, Psychology, Medicine — ограниченное количество мест
   - Процесс: подача до 15 января (deadline), затем lottery / ranking по GPA
   - Для CS в University of Amsterdam, TU Delft, TU/e — Numerus Fixus применяется
   - После 15 января — нельзя изменить приоритеты
   - Selection procedure может включать motivation letter + ranking по оценкам

3. **Language Requirements:**
   - IELTS Academic: 6.0–6.5 overall, no band below 6.0
   - TOEFL iBT: 80–92
   - Some accept Cambridge C1 Advanced (CAE)
   - Для программ на нидерландском: NT2-II

4. **Translations and Legalization:**
   - **Апостиль:** НЕ требуется для Studielink подачи
   - **Перевод:** certified translation на английский или нидерландский
   - Документы должны быть заверены печатью школы (official transcript)

5. **Proof of Funds:**
   - Требуется для residence permit (student visa через university)
   - Сумма: ~€12,000–€14,000 за год
   - Форма: bank statement на имя студента или родителя + affidavit of support
   - University подает за тебя на residence permit (MVV + VVR)

6. **Application Fee:**
   - €100 за application (некоторые universities)
   - Residence permit fee: €207 (платится через university)

**Даты:**
- Numerus Fixus programs: deadline 15 января
- Non-Numerus Fixus: deadline 1 мая (для non-EU)
- Результаты Numerus Fixus: 15 апреля

### 2.6 Swiss Universities

**Типы университетов:**
- **ETH Zurich / EPFL:** Federal Institutes of Technology (топовые, высокая конкуренция)
- **Cantonal universities:** University of Zurich, University of Geneva и др.
- **Universities of Applied Sciences (Fachhochschulen):** более практические

**ETH Zurich / EPFL специфика:**

1. **Entry Requirements:**
   - Российский аттестат + 1–2 года вуза = direct entry (depending on subjects)
   - Или аттестат + 1 год в recognized university + strong grades
   - Alternative: pass Swiss Matura или entrance examination (осень)
   - Для ETH: competitive selection, strong math and physics grades required

2. **Entrance Examination:**
   - Если аттестат не признается полностью — можно сдать entrance exam
   - Basic exam: математика, естественные науки, языки, обществознание
   - Reduced exam (для science track): только math, chemistry, physics
   - Проводится в августе, стоимость ~CHF 200–300

3. **Language Requirements:**
   - **ETH Zurich:** German proficiency (C1/C2) для большинства bachelor programs, либо английский для некоторых
   - **EPFL:** French proficiency (B2/C1) — DELF B2, DALF C1
   - Некоторые новые программы на английском (Data Science at ETH)

4. **Translations and Apostille:**
   - **Апостиль:** требуется для российских документов (Hague Apostille Convention)
   - **Перевод:** certified translation на немецкий, французский или английский
   - Нотариальное заверение копий

5. **Application Fee:**
   - ETH Zurich: CHF 185 (non-refundable)
   - EPFL: CHF 150–200
   - Cantonal universities: CHF 100–200

6. **Tuition and Living Costs:**
   - Tuition: CHF 1,500–2,000 за семестр (очень низкая!)
   - Living costs: CHF 20,000–25,000 за год
   - Proof of funds: CHF 21,000 минимум на счету (часто требуется для visa/permit)

7. **Виза:**
   - Student residence permit
   - Apply within 14 days of arrival
   - Proof of admission, proof of funds, health insurance, passport
   - Processing: 8–12 weeks

**Даты:**
- Deadline: 30 апреля для осеннего семестра
- Entrance exam registration: март–апрель
- Semester start: середина сентября

## 3. Как получить каждый документ

### 3.1 Аттестат о среднем общем образовании

**Где взять:** В школе, где окончил 11 класс.

**Для российских граждан:**
- Аттестат выдается школой в июне после сдачи ЕГЭ
- Если уже есть — проверь, что он в хорошем состоянии, без повреждений
- Приложение к аттестату с оценками — обязательно!
- Если аттестат утерян — запроси дубликат через школу или департамент образования региона (срок: 1–3 месяца)

**Стоимость:** Бесплатно (если оригинал). Дубликат: 500–2000 ₽.

**Сколько времени:** Если оригинал есть — 1 день. Дубликат — 1–3 месяца.

**Пошаговая инструкция:**
1. Найди оригинал аттестата + приложение
2. Сделай 3–4 цветных скана/фотографии в высоком разрешении
3. Проверь, что все страницы читаемы
4. Не отдавай оригинал никому (только для нотариального заверения)

---

### 3.2 Школьный транскрипт (Official School Transcript)

**Где взять:** В школе (завуч по учебной работе, методист, или директор).

**Для российских граждан:**
- Российские школы обычно не выдают "transcript" в американском понимании
- Нужно получить справку со всеми оценками за 9, 10, 11 классы (или полные 11 лет)
- Формат: таблица с предметами, оценками за каждый год, итоговые оценки
- Школа должна заверить печатью и подписью директора
- Некоторые университеты требуют transcript в определенном формате — скачай шаблон с сайта университета и попроси школу заполнить

**Стоимость:** Бесплатно или 200–500 ₽ за справку.

**Сколько времени:** 3–7 рабочих дней.

**Пошаговая инструкция:**
1. Зайди к завучу / директору школы
2. Объясни, что нужна справка с оценками для поступления за рубеж
3. Попроси включить: ФИО, дату рождения, все предметы за 9–11 классы, оценки (5-балльная шкала), дату выдачи
4. Попроси заверить печатью школы и подписью директора
5. Если школа отказывается делать справку — обратись в департамент образования
6. Сделай скан сразу

---

### 3.3 Транскрипт из вуза (если учишься в CUM или другом вузе)

**Где взять:** В деканате / учебном отделе вуза.

**Для российских граждан:**
- Если ты уже студент (например, CUM — City University of Moscow, или любой другой вуз) — нужен academic transcript
- Это важно, если ты подаешься как transfer student или если твой HZB требует 1–2 года вуза
- Транскрипт должен содержать: названия курсов, credits/hours, оценки, grading scale

**Стоимость:** Бесплатно или 200–500 ₽.

**Сколько времени:** 5–10 рабочих дней.

**Пошаговая инструкция:**
1. Иди в учебный отдел / деканат факультета
2. Закажи "справку об успеваемости" или "выписку из зачетной книжки"
3. Попроси заверить печатью и подписью
4. Если университет работает с электронными справками — проверь, принимает ли target university электронные версии
5. Если нет — бери бумажную, заверенную, и сканируй

### 3.4 Перевод на английский (Certified Translation)

**Где взять:**
- Нотариус + переводчик (в России)
- Бюро переводов с нотариальным заверением
- В некоторых случаях — сам university может предложить approved translators
- Для US: credential evaluation agency иногда требует перевода от своих партнеров

**Для российских граждан:**
- Перевод должен быть **certified** — то есть переводчик подтверждает, что перевод точный
- В России это обычно: перевод + нотариальное заверение подписи переводчика
- Нотариус заверяет только подпись переводчика, а не содержание документа
- Для US credential evaluation (WES и др.) — обычно требуется перевод с нотариальным заверением
- Для UK — certified translation через approved translator или sworn translator
- Для Германии — перевод может быть на немецкий или английский

**Стоимость:**
- Перевод аттестата + приложения: 2,000–5,000 ₽
- Нотариальное заверение: 1,500–3,000 ₽ за документ
- Полный комплект (аттестат + транскрипт): 5,000–12,000 ₽
- Если через крупное бюро: до 15,000 ₽

**Сколько времени:** 2–5 рабочих дней.

**Пошаговая инструкция:**
1. Найди бюро переводов с нотариальным заверением (или отдельно переводчика и нотариуса)
2. Сделай ксерокопии аттестата + приложения + транскрипта (нотариус будет заверять копии)
3. Переводчик делает перевод на английский
4. Нотариус заверяет подпись переводчика (и копии оригиналов, если требуется)
5. Получи на руки: оригинал перевода + оригинал нотариального заверения
6. Сделай сканы ВСЕХ страниц (русские и английские версии)

**Важно:**
- Перевод должен быть **word-for-word** (дословным), а не адаптированным
- Сохраняй оригинальную структуру: названия предметов, даты, оценки
- Переводчик должен поставить печать и подпись

### 3.5 Апостиль (Hague Apostille)

**Где взять:**
- Министерство образования региона (для аттестатов)
- Министерство просвещения РФ (для некоторых документов федерального значения)
- Нотариальная палата (для нотариально заверенных документов)

**Для российских граждан:**
- Россия является участником Гаагской конвенции 1961 года
- Апостиль ставится на оригинал документа или на нотариально заверенную копию
- Для аттестата: апостиль в Министерстве образования субъекта РФ, выдавшего документ
- Для нотариально заверенных переводов: апостиль в Нотариальной палате

**Когда нужен:**
- **Германия:** требуется для визы, иногда для Uni-Assist
- **Нидерланды:** может потребоваться для residence permit
- **Швейцария:** обычно требуется
- **US/UK:** обычно НЕ требуется (достаточно credential evaluation или certified translation)

**Стоимость:**
- Министерство образования: 2,500–5,000 ₽ за документ (зависит от региона)
- Нотариальная палата: 1,000–2,500 ₽ за документ
- Услуги посредников: +3,000–10,000 ₽

**Сколько времени:**
- Лично: 1–5 рабочих дней
- Через посредника: 1–2 недели
- Почтой: 2–4 недели

**Пошаговая инструкция:**
1. Определи, какие документы нужно апостилировать (смотри требования университета)
2. Для аттестата:
   - Найди адрес Министерства образования своего региона
   - Позвони и уточни: нужен ли оригинал, нужна ли предварительная запись
   - Принеси оригинал аттестата + приложения
   - Заплати госпошлину
   - Получи документ с апостилем
3. Для нотариальных документов:
   - Иди в Нотариальную палату региона
   - Принеси нотариально заверенный перевод
   - Заплати госпошлину
   - Получи апостиль
4. Сделай скан апостиля сразу
5. Не отдавай оригинал с апостилем без нужды — восстановить дорого

---

### 3.6 Нотариальное заверение

**Где взять:** Любой нотариус.

**Для российских граждан:**
- Нотариус заверяет копии документов или подпись переводчика
- Для международного использования: копия + нотариальное заверение + апостиль (если нужно)
- Важно: нотариус в РФ заверяет только копии документов, выданных в РФ (или переводы)

**Стоимость:**
- Заверение копии: 200–500 ₽ за документ
- Заверение подписи переводчика: 500–1,500 ₽

**Сколько времени:** 15 минут–1 час.

**Пошаговая инструкция:**
1. Найди нотариуса рядом с домом
2. Принеси оригинал документа и ксерокопию (или закажи копию у нотариуса)
3. Нотариус сверит копию с оригиналом и заверит
4. Для перевода: переводчик приходит с паспортом, подписывает перевод при нотариусе

### 3.7 Credential Evaluation (WES, ECE, SpanTran)

**Что это:** Американская или международная организация оценивает твой российский диплом и переводит его в эквивалент US education system.

**Когда нужен:**
- **US public universities:** часто обязателен
- **US private universities:** иногда обязателен, иногда рекомендуется
- **Canada:** обычно обязателен
- **UK / Europe:** редко требуется

**Агентства (популярные):**
- **WES (World Education Services):** самое популярное, многие universities предпочитают
- **ECE (Educational Credential Evaluators):** дешевле WES, быстрее
- **SpanTran:** хорош для international students, дешевле
- **IERF (International Education Research Foundation)**
- **NACES members:** список на naces.org

**Для российских граждан:**
- WES требует: оригинал или заверенную копию аттестата + перевод
- Документы отправляются напрямую из школы / вуза (или через тебя в запечатанном конверте)
- Процесс: создаешь аккаунт, заполняешь application, оплачиваешь, получаешь instructions
- Evaluation report: обычно Course-by-Course (для undergraduate transfer) или Document-by-Document (для admission)

**Стоимость:**
- WES ICAP (с хранением документов): $145 + $30 доставка
- WES Basic: $100
- ECE: $100–$195
- SpanTran: $85–$150

**Сколько времени:**
- WES: 4–7 недель после получения ВСЕХ документов
- ECE: 2–4 недели
- SpanTran: 1–3 недели

**Пошаговая инструкция:**
1. Проверь на сайте университета, какое агентство они принимают
2. Зарегистрируйся на сайте агентства
3. Выбери тип evaluation (Course-by-Course для transfer, Document-by-Document для freshman)
4. Оплати online
5. Получи Reference Number — его нужно указать на всех документах
6. Скачай Academic Records Request Form — отдай в школу / вуз
7. Школа отправляет документы напрямую в агентство (или ты отправляешь в запечатанном конверте)
8. Для российских школ: часто нужно принести документы лично, потому что школы не отправляют международную почту
9. Жди уведомления, что документы получены
10. Жди evaluation report (придет по почте или online, в зависимости от выбора)

**Важно:**
- WES часто требует, чтобы документы пришли напрямую от школы
- Если школа не отправляет — используй courier (DHL, FedEx) из России
- Сроки могут растянуться, если документы "потеряются" — отслеживай!

### 3.8 Рекомендательные письма

**Где взять:** Учителя, научный руководитель, работодатель, ментор.

**Для российских граждан:**
- 2 письма от учителей основных предметов (core subjects) — обязательно для US
- 1 письмо от counselor (школьного психолога / классного руководителя) — обязательно для Common App
- Письма должны быть на английском
- Учитель может написать по-русски, а ты переведешь с certified translation (НЕ рекомендуется — лучше просить написать по-английски)

**Как просить:**
1. Выбери учителей, которые тебя хорошо знают (не обязательно те, у кого 5)
2. Лучше: учитель математики + учитель гуманитарного предмета
3. Подойди лично (или напиши вежливое письмо)
4. Дай минимум 4 недели на написание
5. Предоставь: список достижений, резюме, информацию о университетах, дедлайн
6. Объясни процесс: Common App invite via email, UCAS reference, или sealed envelope

**Стоимость:** Бесплатно (если учитель пишет добровольно).

**Сколько времени:** 2–6 недель (в зависимости от загруженности учителя).

**Пошаговая инструкция:**
1. Составь список 3–4 потенциальных рекомендателей
2. Напиши каждому вежливое письмо:
   - Напомни, где и когда вы работали вместе
   - Объясни, куда поступаешь и почему
   - Попроси рекомендательное письмо
   - Укажи дедлайн (минимум за месяц)
3. При встрече дай "brag sheet" — 1 страница с твоими достижениями
4. Для Common App: введи email рекомендателя в систему — ему придет invite
5. Для UCAS: рекомендатель заполняет reference online через твой центр (school)
6. Проверяй статус в системе — has it been submitted?
7. Напиши thank-you note после подачи

**Совет для российских школ:**
- Если в школе не знают процедуру — объясни сам
- Если counselor не хочет писать — попроси классного руководителя или директора
- Если учителя не говорят по-английски — предложи написать по-русски и перевести (но лучше найти учителя английского или математики, который может написать)

### 3.9 Банковские выписки / Proof of Funds

**Где взять:** Банк, где открыт счет.

**Для российских граждан:**
- В 2026–2027 году из-за санкций российские банки могут иметь ограничения
- Лучше иметь счет в банке, который работает с international transfers (Tinkoff, Сбер, ВТБ — check current status)
- Сумма должна быть на счету минимум 28 дней (для UK) или просто актуальная (для US)
- Для blocked account (Германия): используй international providers (Coracle, Expatrio, Fintiba)

**Стоимость:**
- Выписка из российского банка: 0–500 ₽
- Bank letter на английском: 0–1,000 ₽
- International bank statement (если счет за рубежом): бесплатно–$20
- Blocked account (Германия): €49–€150 открытие + €5–€10/месяц

**Сколько времени:** 1–3 рабочих дня в банке.

**Пошаговая инструкция:**
1. Определи, сколько нужно (смотри требования университета / страны)
2. US: сумма = tuition + $15,000–$25,000 living expenses (за год)
3. UK: сумма = tuition + £11,385–£13,347 living expenses, на счету 28 consecutive days
4. Germany: €11,904 в blocked account
5. Switzerland: CHF 21,000+ proof
6. Netherlands: €12,000–€14,000
7. Иди в банк, запроси "справку об остатке на счете" (account balance certificate)
8. Попроси сделать на английском языке (если возможно) или закажи перевод
9. Справка должна содержать: имя владельца, дату, сумму в валюте, печать банка, подпись
10. Для affidavit of support (если родители спонсируют): нотариально заверенное письмо + их bank statements

**Важно:**
- Для UK: деньги должны лежать 28 дней — не перемещай их перед подачей!
- Для US: affidavit of support (Form I-134) требуется для visa interview
- Если санкции мешают — рассмотри открытие счета в Казахстане, Армении, Грузии, или у родственников за рубежом (но будь готов объяснить)

### 3.10 Паспорт (заграничный)

**Где взять:** МФЦ или МВД (паспортно-визовая служба).

**Для российских граждан:**
- Загранпаспорт нового поколения (биометрический): 10 лет
- Должен быть действителен минимум 6 месяцев после планируемого начала учебы
- Если планируешь поступать в сентябре 2027 — паспорт должен быть действителен до марта 2028 минимум
- Если паспорт истекает в 2027–2028 — продли ЗАРАНЕЕ

**Стоимость:**
- Биометрический загранпаспорт: 5,000 ₽ (госпошлина)
- Ускоренное оформление (в некоторых МФЦ): +2,500–5,000 ₽

**Сколько времени:**
- Обычное оформление: 1–1.5 месяца
- Ускоренное: 2–3 недели (если доступно)

**Пошаговая инструкция:**
1. Запишись через Госуслуги (gosuslugi.ru) или в МФЦ
2. Заплати госпошлину online (скидка 30% через Госуслуги = ~3,500 ₽)
3. Сфотографируйся (фото на загранпаспорт в МФЦ или в фотоателье)
4. Приди в назначенное время с паспортом РФ
5. Получи паспорт лично или через доставку

**Совет:**
- Если у тебя нет загранпаспорта — делай срочно, это блокер для ВСЕГО процесса
- Если паспорт истекает через год — продли сейчас, чтобы не рисковать
- Сделай 10+ ксерокопий паспорта сразу

### 3.11 Справка о прививках (Immunization Record)

**Где взять:** Поликлиника по месту жительства, прививочный кабинет.

**Для российских граждан:**
- Требуется ТОЛЬКО после зачисления (для заселения в кампус)
- US universities требуют: MMR (корь, свинка, краснуха), DTP/DTaP (столбняк), Varicella (ветрянка), Hepatitis B, sometimes meningitis
- UK: TB test для visa (если из listed country)
- Germany / Netherlands: обычно нет требований

**Стоимость:**
- Справка из поликлиники: бесплатно–500 ₽
- Перевод на английский: 1,000–2,000 ₽
- Прививки (если пропущены): 0–5,000 ₽ каждая
- TB test для UK: £100–£200 (в approved clinic)

**Сколько времени:**
- Справка: 1–3 дня
- Прививки (если нужны): 1–3 месяца (с интервалами между дозами)
- TB test: 2–7 дней (ожидание результата)

**Пошаговая инструкция:**
1. Получи форму immunization requirements от университета (обычно присылают после admission)
2. Сходи в поликлинику, возьми справку о прививках (форма 063/у или электронная)
3. Проверь, каких прививок не хватает
4. Сделай недостающие (запланируй заранее — некоторые требуют 2–3 дозы с интервалом)
5. Переведи справку на английский (certified translation)
6. Заполни university immunization form (врач в РФ может подписать)
7. Отправь в university health center

### 3.12 Language Test Scores (TOEFL / IELTS / Duolingo)

**Где сдать:**
- **TOEFL iBT:** test centers в Москве, СПб и других городах, или Home Edition (online)
- **IELTS Academic:** British Council test centers
- **Duolingo English Test:** online, дома

**Для российских граждан:**
- TOEFL и IELTS Home Edition доступны в России (проверь актуальность на 2026)
- Duolingo — самый доступный, принимается многими universities
- Срок действия: 2 года с даты сдачи
- Нужно заказывать official score reports (отправку в universities) — это платная услуга

**Стоимость:**
- TOEFL iBT: $195–$210
- IELTS Academic: $215–$240 (зависит от центра)
- Duolingo: $59
- Отправка TOEFL в universities: $20 за каждый (после первых бесплатных 4 при регистрации)
- Отправка IELTS: бесплатно до 5 institutions (электронно), далее платно

**Сколько времени:**
- TOEFL: результаты через 6 дней, Home Edition — 7–10 дней
- IELTS: результаты через 13 дней
- Duolingo: результаты через 48 часов

**Пошаговая инструкция:**
1. Выбери тест (Duolingo — дешевле, TOEFL/IELTS — более universally accepted)
2. Зарегистрируйся на официальном сайте
3. Выбери дату и центр (или сдай Home Edition)
4. Оплати
5. Готовься минимум 2–4 недели (или больше, если уровень ниже target)
6. Сдай тест
7. Получи результаты
8. Отправь official scores в universities через систему теста

**Совет:**
- Проверь minimum scores для каждого university
- Некоторые universities superscore SAT/ACT, но редко superscore TOEFL/IELTS
- Duolingo принимают не все — проверь список accepting institutions

### Как сократить расходы

1. **Fee waivers:**
   - Common App fee waiver: если семья получает менее $27,000/год (US standard), но для international students — редко
   - Некоторые universities дают automatic fee waiver для international students (check each)
   - CSS Profile fee waiver: применяется автоматически, если твоя семья получит fee waiver в Common App

2. **Бесплатные application days:**
   - Некоторые universities (Carnegie Mellon, Dartmouth и др.) делают free application days — следи за новостями

3. **Test flexibility:**
   - Выбирай test-optional schools, чтобы не платить за SAT/ACT
   - Сдай Duolingo вместо TOEFL/IELTS ($59 против $210+)
   - Но: Duolingo принимают не все, и strong TOEFL/IELTS score помогает admission

4. **Credential evaluation:**
   - ECE дешевле WES
   - SpanTran — один из самых дешевых
   - Некоторые universities не требуют evaluation (check!)

5. **Доставка:**
   - Используй электронные transcripts, где возможно (бесплатно)
   - Не отправляй оригиналы без нужды — сканы accepted многими universities на этапе review

6. **Раннее планирование:**
   - Делай загранпаспорт через Госуслуги (скидка 30%)
   - Заказывай переводы и апостили группой (скидки)
   - Подавай рано — избегай rush fees

## 6. Частые ошибки с документами

### Ошибки на этапе подачи

**1. Неправильный перевод**
- Ошибка: Google Translate или не-certified перевод
- Последствия: rejection или request for new documents (задержка на недели)
- Как избежать: используй только professional certified translators, сохраняй структуру документа

**2. Потерянные рекомендательные письма**
- Ошибка: не отслеживать статус, дать мало времени учителю
- Последствия: incomplete application, не будет рассмотрена
- Как избежать: запрашивай за 6 недель, проверяй status online, напоминай за 2 недели до deadline

**3. Неправильное имя в разных документах**
- Ошибка: в паспорте — Ivanov Ivan, в аттестате — Ivanov Ivan Petrovich, в тестах — Ivan Ivanov
- Последствия: mismatch, delay in processing, visa denial
- Как избежать: используй ВСЕГДА одно написание (как в паспорте), проверь consistency ВЕЗДЕ

**4. Просроченный паспорт**
- Ошибка: паспорт истекает через 3 месяца после планируемого отъезда
- Последствия: visa denial, нельзя сдать тесты
- Как избежать: проверь expiration date сейчас, продли, если истекает в течение 18 месяцев

**5. Отправка оригиналов, когда достаточно сканов**
- Ошибка: отправляешь оригинал аттестата в university
- Последствия: документ может потеряться, дорого восстанавливать
- Как избежать: читай instructions — most US/UK universities accept certified scans на этапе application; оригиналы требуются редко

**6. Неправильный тип credential evaluation**
- Ошибка: заказываешь Document-by-Document, а university требует Course-by-Course
- Последствия: нужно заказывать заново, $100+ и 3–4 недели
- Как избежать: внимательно читай requirements на сайте university, пиши в admission office

**7. Просроченные тесты**
- Ошибка: TOEFL сдан в 2024 году, а application в 2027
- Последствия: тест не принимается (valid 2 года), нужно пересдавать
- Как избежать: проверь validity, планируй сдачу не раньше 12 месяцев до deadline

**8. Неполный CSS Profile**
- Ошибка: заполняешь для одного родителя, когда требуется обоих
- Последствия: financial aid не рассчитывается, delay
- Как избежать: читай instructions внимательно, используй Noncustodial Parent Profile если родители разведены

### Ошибки на этапе визы

**9. Недостаточно средств на счету**
- Ошибка: на счету $20,000, а tuition + living = $45,000/год
- Последствия: visa denial
- Как избежать: рассчитай точную сумму (tuition + $15,000–$25,000 living), убедись, что деньги лежат нужное время

**10. Перемещение денег перед визой**
- Ошибка: положил $30,000 на счет, через 10 дней перевел часть, потом снова положил
- Последствия (UK): не выполнен 28-day rule — visa refusal
- Как избежать: не трогай счет минимум 28 дней перед подачей; используй отдельный savings account

**11. Неправильная виза**
- Ошибка: подаешь на tourist visa вместо student visa
- Последствия: refusal, potential ban
- Как избежать: всегда подавай на правильную категорию (F-1 для US, Student Route для UK, etc.)

### Что делать, если документ отклонен

**Если university отклонил документ:**
1. Прочитай email внимательно — какая именно проблема?
2. Спроси clarification у admission office (вежливо)
3. Исправь и переотправь сразу
4. Если нужен новый перевод — сделай urgent (2–3 дня)
5. Если потеряли документ — отправь через courier с tracking
6. Попроси extension, если delay не твоя вина

**Если виза отклонена:**
1. Прочитай refusal letter — причина?
2. Common reasons: insufficient funds, intent to immigrate, missing documents, incorrect information
3. Исправь проблему и подай заново (reapply)
4. US: можно подать new DS-160 и новый interview
5. UK: Administrative Review (если считаешь, что ошибка) или новая подача
6. Germany / Europe: исправь deficiency и подай заново
7. Всегда будь честным — inconsistency ведет к long-term bans

**Если потерял оригинал аттестата:**
1. Немедленно запроси дубликат в школе / департаменте образования
2. Объясни situation — для international university admission (иногда ускоряют)
3. Срок: 1–3 месяца
4. Если deadline близко — попроси у university accept provisional document + letter from school

### Чеклист для предотвращения ошибок

Перед подачей каждого документа проверь:
- [ ] Имя совпадает с паспортом ВЕЗДЕ
- [ ] Даты логичны и consistent
- [ ] Перевод certified и полный
- [ ] Сканы читаемые (300 dpi+, PDF)
- [ ] Оригинал не отдан без нужды
- [ ] Документ в сроке действия (passport, tests)
- [ ] Сумма на счету достаточна и не трогалась 28 дней
- [ ] Рекомендательные письма submitted и positive
- [ ] Нет конфликтов в financial documents (CSS Profile = bank statements)
- [ ] Все deadlines в календаре с reminders за неделю
