# Soft Skills: Leadership, Mentorship, Собеседования

> **Цель:** Перейти от "отличный инженер" к "отличный инженер, с которым хотят работать"
> **Формат:** Практика + reflection + feedback
> **Время:** Постоянно, результат через 6-12 месяцев

---

## Почему это важно

В top-компаниях и вузах soft skills — **не бонус, а requirement**:
- Google: "Googleyness" — как ты взаимодействуешь с людьми
- MIT: Recommendation letters оценивают character
- Startups: Founder с $600K опытом должен убеждать инвесторов

| Hard skills only | Hard + Soft skills |
|------------------|-------------------|
| Решает задачи | Решает задачи + ведет команду |
| Пишет код | Пишет код + менторит |
| Отвечает на вопросы | Задает правильные вопросы |
| Работает один | Создает synergy |

## 1. Leadership

### Что это значит для инженера

**Не:** Ты boss, все слушаются
**Да:** Ты берешь ответственность, ведешь к результату, поддерживаешь других

### Как развивать

**В текущей работе:**
- Волонтерься leadить новый проект
- Предлагай архитектурные решения
- Организуй tech talks в команде
- Напиши RFC (Request for Comments) на важное изменение

**В open-source:**
- Стань maintainer проекта
- Review чужие PR с constructive feedback
- Помогай новичкам в issues

**В pet project:**
- Пригласи 1-2 человек поучаствовать
- Распредели задачи
- Проводи sync meetings

### Книги

| Книга | Автор | Почему |
|-------|-------|--------|
| "Extreme Ownership" | Jocko Willink | Ответственность |
| "The Manager's Path" | Camille Fournier | Карьера tech lead |
| "Turn the Ship Around" | L. David Marquet | Поддерживающее лидерство |
| "Radical Candor" | Kim Scott | Честный feedback |

## 2. Mentorship

### Почему это важно

- Для вузов: "Can this person contribute to the community?"
- Для работы: Senior = тот, кто растет других
- Для тебя: Обучение — лучший способ учиться

### Как начать

**Шаг 1: Найди менти**
- Junior в твоей команде
- Студент в Telegram-чате
- Человек на Habr, который задает вопросы

**Шаг 2: Формат**
- 30-60 минут в неделю
- Темы: код review, career advice, learning path
- Не решай за них — направляй

**Шаг 3: Оформи формально**
- T-Bank mentorship program
- JetBrains Academy mentor
- CodePath mentor
- Coursera mentor

### Чеклист ментора

- [ ] Найти 1-2 менти
- [ ] Проводить встречи регулярно
- [ ] Дать менти первый code review
- [ ] Помочь с career plan
- [ ] Получить feedback от менти
- [ ] Получить recommendation letter

## 3. Communication

### Техническая коммуникация

**Письменная:**
- RFC документы
- Architecture Decision Records (ADR)
- Post-mortems
- Tech blog posts

**Устная:**
- Tech talks (10-30 минут)
- Demo days
- Conference presentations
- Mock interviews

### Как практиковать

| Частота | Активность |
|---------|-----------|
| Еженедельно | Писать 1 tech note |
| Ежемесячно | Проводить 1 tech talk |
| Каждые 3 мес | Выступать на митапе |
| Каждые 6 мес | Подавать CFP на конференцию |

### Книги

| Книга | Автор | Почему |
|-------|-------|--------|
| "On Writing Well" | William Zinsser | Ясность в тексте |
| "Presentation Zen" | Garr Reynolds | Презентации |
| "Talk Like TED" | Carmine Gallo | Публичные выступления |

## 4. Собеседования

### Mock Interviews

**Почему:** Даже отличный инженер может провалить собеседование из-за нервов

**Ресурсы:**

| Платформа | Что | Стоимость |
|-----------|-----|-----------|
| Pramp | Бесплатные mock interviews | Free |
| interviewing.io | Анонимные mock с инженерами | $150-300 |
| Exponent | PM + tech mock | $100-200 |
| Friends | Друг-инженер | Free |

**График:**
- 1 mock interview в 2 недели (алгоритмы)
- 1 mock interview в месяц (system design)
- 1 mock interview в месяц (behavioral)

### Behavioral Interviews

**Формат:** STAR (Situation, Task, Action, Result)

**Типичные вопросы:**
- "Расскажи о сложном проекте"
- "Как ты справлялся с конфликтом?"
- "Расскажи о failure"
- "Как ты prioritизируешь задачи?"

**Подготовка:**
- Записать 10 историй из опыта
- Отрепетировать вслух
- Получить feedback

### Книги по интервью

| Книга | Для чего |
|-------|----------|
| "Cracking the Coding Interview" | Алгоритмы + behavioral |
| "Decode and Conquer" | System design interviews |
| "Elements of Programming Interviews" | Задачи по темам |

## 5. Emotional Intelligence

### Самые важные навыки

1. **Self-awareness:** Понимаешь свои эмоции и триггеры
2. **Empathy:** Понимаешь других
3. **Resilience:** Восстанавливаешься после failure
4. **Adaptability:** Меняешься под обстоятельства
5. **Conflict resolution:** Решаешь конфликты конструктивно

### Как развивать

- **Reflection journal:** Что прошло хорошо/плохо сегодня?
- **Feedback:** Просить обратную связь регулярно
- **Therapy/coaching:** Профессиональная поддержка
- **Mindfulness:** Медитация, осознанность

### Книги

| Книга | Автор | Почему |
|-------|-------|--------|
| "Emotional Intelligence" | Daniel Goleman | Фундамент |
| "Mindset" | Carol Dweck | Growth mindset |
| "Nonviolent Communication" | Marshall Rosenberg | Конфликты |
| "The Subtle Art of Not Giving a F*ck" | Mark Manson | Resilience |
