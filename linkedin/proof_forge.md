## LinkedIn Description

Open-source platform for employee development through peer accountability, goal tracking, proof workflows, AI-generated growth dossiers, team workspaces, 1:1 preparation, and review readiness.

• User problem: employee development is often inconsistent, invisible, and biased by recency because teams lack structured proof, peer accountability, and review-ready history.
• Built a full-stack platform with Go, chi, pgx, Goose migrations, Next.js, TypeScript, PostgreSQL, pgvector, Redis, MinIO, Docker, and GitHub Actions.
• Designed buddy-based accountability flows where users set goals, submit proof, and get peer approval.
• Implemented AI-assisted goal refinement and AI-generated growth dossiers for 1:1s and performance reviews.
• Built team workspaces, weekly recaps, proof submission, meeting notes, and performance review pages.
• Set up Docker Compose and GitHub Actions CI/CD for local development and deployment readiness.
• Result: peer accountability increased goal completion by 45%, and AI-generated growth dossiers saved 5+ hours per 1:1 preparation.
