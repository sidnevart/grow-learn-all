## LinkedIn Description

Workflow automation for cashback campaign management, audience setup, partner integration monitoring, and result tracking.

• Business problem: setting up a cashback campaign meant 3+ minutes clicking through frontend forms and parameter selectors for every run — a slow, repetitive UI workflow when a single message or command should have been enough.
• Built automation workflows using n8n, JavaScript, REST APIs, PostgreSQL, and internal platform integrations.
• Automated campaign creation, audience builder execution, partner region setup, status checks, logging, and result summaries.
• Designed workflows with explicit execution states so business and engineering users could see which step failed and why.
• Added monitoring and structured logs for campaign execution, integration status, and operational follow-up.
• Reduced campaign setup time by 70% and automated 15+ repetitive manual tasks per week.
• Related automation around partner region setup saved 40-60 hours of manual work per month.
