## LinkedIn Description

Local-first platform for reproducible AI-agent work in real codebases. ARC combines provider adapters, project memory, execution artifacts, context controls, and rule management to make AI-agent workflows safer and more transparent.

• User problem: running AI agents on production codebases is expensive, hard to reproduce, and risky when context, memory, tool use, and execution artifacts are not controlled.
• Built a local-first AI-agent environment using Go, Wails, provider adapters, memory systems, execution artifacts, and project-level rule management.
• Designed context controls to reduce unnecessary prompt load while keeping enough project knowledge for high-quality responses.
• Added provider abstraction to avoid vendor lock-in and support different models/workflows.
• Made agent work inspectable through local artifacts, execution history, embedded diagrams, mini-apps, demos, and simulations.
• Result: reduced context load by 48% without lowering response quality.
