## LinkedIn Description

University competitive coding platform where students solve problems simultaneously with real-time game mechanics, live progress tracking, sabotage actions, and spectator views.

• User problem: traditional competitive coding platforms felt static and isolated; university tournaments needed more live interaction and transparency.
• Built a real-time coding arena where participants solve the same tasks simultaneously and spectators can track attempts, successes, solved tasks, and progress.
• Implemented sabotage mechanics such as "bombs" that can reset part of another participant's solution, making contests more game-like and engaging.
• Built frontend and backend components with TypeScript, React, Node.js, WebSocket, and PostgreSQL.
• Added leaderboard, spectator mode, participant status, and transparent real-time competition state.
• Result: 80+ students participated, 10+ active competitions per day, and 240+ GitHub issues resolved across the open-source project.

## Short Version

Built CUMock, a real-time competitive coding platform for Central University with coding battles, sabotage mechanics, spectator mode, WebSockets, and live leaderboards. 80+ students participated, with 10+ competitions/day and 240+ GitHub issues resolved.
