## LinkedIn Description

CI-integrated AI automation that detects technical debt, generates refactoring plans, creates branches, and prepares draft merge requests for human approval.

• Business problem: legacy code and flaky pipelines slowed product work, while manual refactoring competed with delivery priorities.
• Built an automated refactoring workflow with Python, GitLab CI, Docker, Kotlin, Java, and existing CI infrastructure.
• Designed tech-debt detection heuristics for repeated code patterns, fragile tests, and maintainability issues.
• Created a branch/MR generation flow where the bot prepares draft changes, runs tests, and leaves final approval to engineers.
• Added pipeline timeline visibility: detected debt, planned change, generated branch, MR status, human approval, and CI result.
• Improved engineering safety by keeping AI-generated refactors behind test execution and human review gates.
• Result: contributed to CI/CD acceleration by 30%, saved 20 minutes per pipeline run, and helped eliminate all flaky tests.

## Short Version

Built a GitLab CI refactor bot that detects technical debt, proposes changes, prepares draft MRs, and runs tests before human approval. The broader CI/CD work accelerated pipelines by 30%, saved 20 minutes/run, and eliminated flaky tests.
