## LinkedIn Description

Telegram Mini App and backend automation for a billiards club: booking, match tracking, Elo rating, loyalty flows, and YClients integration.

• Business problem: the club needed booking, loyalty, and game-related flows inside Telegram, while keeping data synchronized with existing club management software.
• Built booking flows with contact-based registration, customer profile state, and Telegram Mini App frontend.
• Implemented match tracking and Elo rating logic to make the product more engaging than a simple booking interface.
• Integrated YClients loyalty operations: bonus debit/credit, booking records, result confirmation, settlement retries, and webhook handling.
• Built backend services with Python, FastAPI, SQLAlchemy, PostgreSQL, Redis, Telegram bot runtime, nginx, Docker Compose, and deployment automation.
• Built frontend with React, TypeScript, Vite, Tailwind, and Telegram Mini App SDK.
• Added retry handling around failed bonus settlement so loyalty operations could recover safely instead of leaving inconsistent state.

## Short Version

Built a Telegram Mini App and backend for a billiards club: bookings, match tracking, Elo rating, loyalty bonuses, YClients webhooks, retry-safe settlement, React frontend, and FastAPI/PostgreSQL/Redis backend.
