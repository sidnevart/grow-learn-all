# LinkedIn Profile Guide for Artem Sidnev

This file is a practical guide for turning the current CVs and extra experience notes into a stronger LinkedIn profile. The ready-to-paste sections are written in English because LinkedIn should support international recruiter search.

## Positioning

Recommended positioning:

> Backend Software Engineer focused on data-intensive systems, internal platforms, workflow automation, and AI-enabled engineering tools.

Secondary angle:

> Backend engineer with strong AI automation and platform-building experience, especially in banking, analytics, Telegram Mini Apps, and internal developer productivity.

Do not position the profile only as "Backend Developer". The strongest story is the combination of backend, data, internal platforms, automation, and applied AI.

## Headline

Use one of these.

### Recommended

```text
Backend Software Engineer | Java, Kotlin, Go, Python | Data-Intensive Systems, Internal Platforms & AI Automation
```

Why this works: it contains the core role, major languages, and searchable domains without sounding inflated.

### More AI-focused

```text
Backend Software Engineer | AI Automation, RAG & Internal Platforms | Java, Kotlin, Go, Python, ClickHouse
```

Use this if you want more recruiter traffic for AI platform and AI automation roles.

### More backend/data-focused

```text
Backend Engineer | Data-Intensive Systems, ClickHouse, Kafka, Spring Boot | Building Platforms & Automation Tools
```

Use this if you want to target classic backend/platform roles first.

Avoid:

```text
Open to work
Software Engineer at T-Bank
Backend Developer
```

These are weaker for search and do not explain your value.
