# LinkedIn профиль: как заполнить на английском

Цель профиля: чтобы рекрутеры находили тебя по backend/platform/AI automation запросам, а человек за 20-30 секунд понимал, что ты не просто backend developer, а инженер, который строит data-intensive backend, internal platforms и AI-enabled engineering workflows с измеримым impact.

## 1. Позиционирование

Основная линия:

```text
Backend / Platform Engineer focused on data-intensive systems, internal platforms, workflow automation, and AI-enabled developer productivity.
```

Не позиционируй профиль только как `AI Engineer`: у тебя сильнее и надежнее выглядит связка `Backend + Platform + Data + AI Automation`. Это лучше проходит ATS/RSM и шире подходит под вакансии Backend Software Engineer, Platform Engineer, Developer Productivity Engineer и AI Platform Engineer.

## 2. Headline

Рекомендованный вариант:

```text
Backend / Platform Engineer | Java, Kotlin, Go, Spring Boot | AI Automation & Developer Productivity
```

Более backend/data вариант:

```text
Backend Software Engineer | Java, Kotlin, Spring Boot, Kafka, ClickHouse | Data-Intensive Systems
```

Более AI/platform вариант:

```text
AI Platform Engineer | Backend Systems, RAG, AI Agents, Internal Tools | Java, Kotlin, Go, Python
```
