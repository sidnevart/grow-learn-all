# Wellfound (AngelList Talent) — Полный гайд

> **Платформа:** wellfound.com (ранее AngelList Talent)
> **Фокус:** Стартапы, seed/Series A/Series B, tech-роли
> **Для кого:** Инженеры, ищущие роли в стартапах US/EU, remote-first компаниях
> **Время на заполнение:** 2-3 часа качественно

---

## Чем Wellfound отличается от LinkedIn

| Критерий | LinkedIn | Wellfound |
|----------|----------|-----------|
| **Аудитория** | Все компании | Стартапы, tech |
| **Hiring процесс** | Рекрутер ищет тебя | Ты express interest, компания отвечает |
| **Фокус** | Career history | What you want next |
| **Equity** | Не обсуждается | Прозрачно: salary + equity |
| **Remote** | Иногда | Основной формат |
| **Скорость** | Медленно | Быстро (ответ за дни) |
| **Visa** | Не указано | Visa sponsorship отмечается |

**Ключевой insight:** На Wellfound тебя не ищут — ты主动表达 interest, и стартапы отвечают. Профиль должен быть заточен под "что ты хочешь делать", не "что ты делал".

## Структура профиля

### 1. Headline / Tagline (коротко, четко)

**Не:** "Backend Engineer at T-Bank"
**Да:** "Backend Engineer | 30M txns/day | Java/Kotlin/Go | Distributed Systems | AI-curious"

**Формула:** Role | Key metric | Stack | Interest area

**Примеры для твоего профиля:**
```
Platform Engineer | 30M txns/day | Java/Kotlin/Go | Seeking AI/ML infra roles
Backend Engineer | ClickHouse/Kafka | Building for scale | Open to US/EU startups
Senior Backend Developer | Distributed systems | Former T-Bank | MIT/Stanford MS track
```

**Ограничение:** ~80 символов на preview. Первые 40 самые важные.

---

### 2. Bio / About (150-300 слов)

**Структура:**
1. Who you are (2 sentences)
2. What you built (metrics, stack)
3. What you want next (startup stage, role type)
4. Fun fact / personality

**Пример:**
```
I'm a backend/platform engineer who has spent 3+ years building 
high-throughput financial systems at T-Bank. My team processes 30M+ 
transactions daily using Java, Kotlin, Go, ClickHouse, and Kafka.

What drives me: turning complex distributed problems into simple, 
reliable systems. I'm obsessed with latency optimization and 
data-intensive architectures.

What I'm looking for: a fast-growing startup (Series A/B) where I 
can own infrastructure decisions and help scale from 1K to 1M users. 
Particularly excited about AI/ML infrastructure, fintech, and 
developer tools.

Side quest: currently learning MIT 6.006 and preparing for MS 
applications. Always happy to talk distributed systems or 
engineering leadership.
```

**Что добавить для international/remote:**
```
Location: Moscow, Russia. Open to relocation (US/EU) or remote 
roles. Have experience working with distributed teams across time 
zones.
```

**Что добавить для AI/ML angle:**
```
Recently built an AI-powered code review bot and a RAG pipeline 
for financial document analysis. Exploring the intersection of 
backend systems and machine learning.
```

- [ ] Pre-seed
- [x] Seed

- [x] Series B

**Почему Series A/B:** Ты senior enough для ownership, но еще можно войти до масштабной корпоративности.

#### Company Size
- [ ] 1-10
- [x] 11-50
- [x] 51-200
- [ ] 201-500

#### Location
- [x] Remote
- [x] San Francisco
- [x] New York
- [x] London
- [x] Berlin
- [x] Amsterdam
- [ ] Other (указать конкретно)

**Для российского гражданина:**
- Отмечай **Remote** как основной (много remote-first стартапов)
- Добавь города, куда готов релоцироваться
- В bio упомяни готовность к relocation

#### Visa Sponsorship
- [x] Will require sponsorship (если ищешь on-site в US/EU)
- [ ] Will not require sponsorship (если remote или есть паспорт)

#### Salary Expectations (опционально, но рекомендуется)

**Для remote roles:**
```
$120,000 - $180,000/year + equity
```

**Для US on-site:**
```
$150,000 - $220,000/year + equity
```

**Для EU:**
```
€80,000 - €130,000/year + equity
```

**Совет:** Wellfound показывает salary ranges компаний. Ставь range, который пересекается с твоими target компаниями.

## Как искать и откликаться на вакансии

### Поиск

**Фильтры:**
1. Role: Backend Engineer / Platform Engineer
2. Location: Remote (если visa issues) или target city
3. Company stage: Seed / Series A / Series B
4. Salary: Укажи свой range
5. Visa sponsorship: Filter accordingly

**Keywords для поиска:**
- "Distributed systems"
- "High throughput"
- "AI infrastructure"
- "Fintech"
- "Data platform"
- "Backend"

### Express Interest (отклик)

**Не просто жми "Apply". Напиши note.**

```
Hi [Founder/Recruiter name],

I came across [Company] and I'm really excited about what you're 
building in [area]. At T-Bank, I led backend infrastructure for 
a system processing 30M+ daily transactions using Java/Kotlin/Go, 
ClickHouse, and Kafka.

I'm particularly interested in [specific aspect of their product]. 
I'd love to contribute my distributed systems experience to help 
scale [Company] to the next level.

Let me know if you'd like to chat!

Artem
```

**Длина:** 80-120 слов. Коротко, по делу, персонализированно.

**Что упомянуть:**
- Почему именно эта компания (покажи, что изучил)
- Релевантный опыт (1-2 achievements)
- Что ты можешь принести

## Частые вопросы для стартапов

### Q: Will you require visa sponsorship?
**A:** "For remote roles — no. For on-site in US/EU — yes, I'm willing to explore visa options (H-1B, O-1, or EU Blue Card depending on location)."

### Q: What's your timeline?
**A:** "Open to immediate start for the right opportunity. Ideally within 1-2 months."

### Q: Why are you leaving T-Bank?
**A:** "Looking for a smaller, faster-moving environment where I can have broader ownership and work on AI/ML infrastructure. Excited about the startup stage."

### Q: What are your salary expectations?
**A:** "For remote roles: $120-180K + meaningful equity. For US on-site: $150-220K + equity. Flexible depending on the opportunity."

### Q: Have you worked in a startup before?
**A:** "While T-Bank is a large company, our team operated with startup speed — we built and deployed the cashback platform from scratch in 6 months with a team of 4."

## Психология стартап-hiring

### Что стартапы ценят

| Quality | Как показать |
|---------|--------------|
| **Speed** | "Built MVP in X weeks" |
| **Ownership** | "Led project from 0 to production" |
| **Impact** | "Improved metric by X%" |
| **Learning agility** | "Learned Go in 3 months for system rewrite" |
| **Cultural fit** | Покажи personality в bio |

### Что стартапы не любят

- "I only work with X stack" (startups меняют стек)
- "I need clear requirements" (в стартапах их нет)
- "I prefer big teams" (стартап = маленькая команда)
- "What's the WLB?" (не спрашивай на первом этапе)

## Еженедельная рутина на Wellfound

| День | Действие |
|------|----------|
| **Пн** | Найти 10 новых вакансий, отфильтровать по релевантности |
| **Вт** | Отправить 5 express interest с персонализированными notes |
| **Ср** | Ответить на все входящие сообщения |
| **Чт** | Обновить статус "Open to work", проверить profile views |
| **Пт** | Поискать новые компании, добавить в saved |
| **Сб-Вс** | Подготовиться к интервью (если назначены) |

**Цель:** 20 express interest в месяц → 5-10 ответов → 2-3 интервью.
